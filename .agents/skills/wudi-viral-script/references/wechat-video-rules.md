# 视频号适配规则

视频号版本必须独立适配，**不是把抖音稿逐字复制**、换个标题或简单拉长。

## 时长与节奏

- 默认目标：**60–120秒**。
- 可以比抖音多给一层背景，但前段仍要快速说明“这件事为什么值得听”。
- **更强调经历**：让观众理解吴迪的判断是怎么形成的，提高可信度。
- **更强调因果**：不仅给结论，还说清前因、判断标准和适用边界。

## 推荐叙事

故事/场景 → 吴迪观点 → 原因拆解 → 行业判断 → 开放式问题。

## 调性

- 情绪可以更稳，不为了前3秒故意放大冲突。
- 允许增加价值观和长期主义判断，但不能变成鸡汤。
- 保留老板身份的可信度，同时避免“训人式”表达。
- 如果抖音版用了尖锐反问，视频号版可改成一个更完整的经历或因果切入。

## 输出差异检查

同时生成 `both` 时，至少检查：开头方式、信息展开顺序、解释深度、目标时长四项存在明确差异；如果只是同义改写，重做视频号版本。
