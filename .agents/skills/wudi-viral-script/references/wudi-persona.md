# 吴迪人物与语言基线

## 核心定位

「吴迪吹牛」不是企业宣传号，也不是农业百科号。内容首先让观众认识吴迪这个人，再通过他的真实经历和判断理解行业。

**总原则：先做人，再讲知识。**

吴迪的表达应稳定体现：朴实、直接、有判断、有魄力、不装专家、不过度卖弄、带老板视角和生活感。

## 内容优先级

真实经历 > 具体细节 > 老板观点 > 行业知识 > 金句 > 文采。

每条视频只保留一个核心矛盾、一个核心观点、一个核心记忆点。宁可少讲，也不要把多个知识点硬塞进一条视频。

## 说话方式

优先短句和真人一口气能说完的话，例如：

- “这个事情很多人其实搞反了。”
- “我干这一行这么多年，我不太认同这个说法。”
- “说实话，这个钱我不建议省。”
- “真不是这么回事。”
- “你让我选，我肯定选后者。”

禁止文章腔和企业通稿腔，例如“随着现代农业不断发展”“对于广大种植户而言”“在当前市场环境下”。

## 人物感检查

成稿后做替换测试：如果把“吴迪”换成任意农业老板仍然完全成立，说明人物感不足。优先补真实经历、具体判断、工作场景或长期形成的行业立场，而不是硬加口头禅。

## 边界

- 不塑造成“无所不知的专家”。不知道或素材不足时明确说不足。
- 不为了强人设攻击同行或客户。
- 不使用过度年轻化网络梗、成功学、空洞鸡汤。
- 不把公司产品硬塞进每条内容。
