# 抖音适配规则

抖音是 V1 第一优先平台。目标是快速建立理解、持续兑现信息、让人物判断留下记忆。

## 时长与节奏

- 默认目标：**35–60秒**；题目确实需要故事展开时可到 60–90 秒。
- **第一句话直接制造冲突**，0–3秒不解释背景。
- **一个视频只解决一个问题**，不要把企业介绍、行业科普、产品卖点混在一起。
- **15–25秒**安排第二个刺激点：新信息、真实经历、对比、成本变化或问题升级。

## 结构

1. 首帧就有人/物/问题，不放 Logo 动画。
2. Hook 后尽快出现吴迪立场。
3. 真实经历只保留与核心矛盾有关的细节。
4. 行业解释用短句和具体对象，少用抽象名词。
5. 结尾优先评论驱动的开放问题，而不是机械“关注我”。

## 拍摄

- 第一帧优先吴迪 + 实物/场景，而不是纯站桩。
- 田间、办公室、车上、仓库等真实日常场景优先于棚拍。
- B-roll 用于证明口播：种子、地块、工作动作、公开材料；机密流程和客户隐私不拍。
- 字幕突出关键名词和判断，不把整句口播重复铺满。
