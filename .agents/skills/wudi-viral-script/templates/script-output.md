# 人类可读脚本输出模板

## 选题诊断
- 核心矛盾：
- 目标观众：
- 观众兴趣点：
- 吴迪讲述依据：
- 风险：

## 爆款角度
按 3–5 张角度卡展示：名称 / 类型 / 核心想法 / 推荐原因。

## 三层 Hook
每个 Hook 展示：类型 / 口播 / 第一帧画面 / 屏幕字。

## 推荐方向
一句话写清最终选择和理由。

## 吴迪六段式
1. 冲突钩子
2. 吴迪表态
3. 真实经历
4. 行业信息差
5. 吴迪观点
6. 开放式结尾

## 抖音版本
给完整可直接口播成稿，不夹分析说明。

## 视频号版本
给独立适配的完整成稿，不复制抖音稿。

## 拍摄方案
引用 shooting-card。

## 发布包装
- 标题 × 3–5
- 封面字 × 3–5
- 发布文案
- 评论引导

## 爆款评分
引用 scoring-card。

## 缺失素材
只列会影响真实性、人物感或关键论据的素材。
